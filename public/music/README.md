# Музыка для «колонок зоны»

Положите треки со свободной лицензией в три папки — по темпу:

| Папка   | Темп      | Что подходит                                   |
| ------- | --------- | ---------------------------------------------- |
| `slow/` | медленный | эмбиент, пианино, лаунж до ~80 BPM             |
| `mid/`  | средний   | лаунж, ню-джаз, chillhop ~85–105 BPM           |
| `fast/` | быстрый   | deep house, nu-disco, фанк ~110–125 BPM         |

Форматы: `.mp3`, `.ogg`, `.m4a`, `.aac`, `.wav`, `.flac`, `.webm`, `.opus`.

После добавления файлов выполните `npm run music` (или просто перезапустите `npm run dev` / `npm run build` —
манифест `manifest.json` пересобирается автоматически). Плеер берёт список треков из манифеста,
перемешивает их и переключает папку при смене темпа с кроссфейдом.

**Файлов нет?** Ничего страшного: плеер сам синтезирует эмбиент нужного темпа через Web Audio
(slow — пэд и колокольчики, mid — лаунж с арпеджио, fast — хаус-грув), и демо работает без файлов.

## Где взять музыку со свободной лицензией

- [Free Music Archive](https://freemusicarchive.org/) — фильтр по лицензиям CC BY / CC0
- [ccMixter](https://ccmixter.org/) — Creative Commons
- [Pixabay Music](https://pixabay.com/music/) — лицензия Pixabay (можно использовать в заведении)
- [Incompetech (Kevin MacLeod)](https://incompetech.com/music/royalty-free/) — CC BY 4.0

Проверьте условия лицензии для публичного воспроизведения и, если нужно, укажите авторов.
